# Kapsy

Application Node (Express) + React (Vite).

## Structure

- `client/` : frontend React (Vite)
- `server/` : API Node/Express

## Démarrer

```bash
npm install
npm run dev
```

- Frontend : http://localhost:5173
- API : http://localhost:3001 (les requêtes `/api` du frontend y sont redirigées)
